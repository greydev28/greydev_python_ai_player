# Curriculum review and alignment notes

The supplied repository already has substantial material for collections, functions, OOP, file handling, Pythonic features, and professional Python. This update preserves those folders and adds missing entry points and a path into data science and AI engineering.

## Alignment with Python Crash Course (3rd edition)
Eric Matthes' *Python Crash Course* is organised around a beginner-friendly introduction followed by project work (including a game, data visualisation, and a web application). This playbook follows the same broad pedagogy: learn one concept, solve focused exercises, then integrate it into a project. It does not copy the book's text or proprietary exercises. Use the official book and companion code as a parallel reference.

Suggested cross-study:
- PCC fundamentals on variables, strings, numbers, lists, and working with lists ↔ Parts 01–03 here.
- PCC `if` statements, dictionaries, user input, and `while` loops ↔ Parts 01–03.
- PCC functions, classes, files, testing, and code style ↔ Parts 03–08.
- PCC projects ↔ use CampusFlow and the capstones as original integration projects.
- PCC data visualisation ↔ Part 09, followed by machine learning in Part 10.

## Primary references selected
- Python official tutorial and library documentation for language behaviour.
- *Python Crash Course*, Eric Matthes, 3rd edition, and its official companion resources for beginner pedagogy and project-based practice.
- scikit-learn official getting-started material for fitting, preprocessing, pipelines, model selection, and evaluation.
- PyTorch official beginner series for tensors, data loaders, models, autograd, optimisation, and saving/loading models.
- FastAPI official tutorial for API implementation.

## Honest limitations
This repository is a self-study curriculum, not an accredited qualification and not a guarantee of employment. It cannot replace feedback from experienced engineers, reading full documentation, or building projects for real users. Library APIs change; consult the current official documentation when installing or deploying.
